# Demo: Agente de consultas y onboarding bancario

Industria: Servicios Financieros  
Escenario: Atención al cliente digital  
Demo: Agente de consultas y onboarding bancario  
Stack conceptual: Copilot Studio + Azure AI Foundry  

Esta demo es un frontend estático para GitHub Pages. La IA no está conectada a servicios reales; las respuestas se simulan en el navegador con una base de conocimiento local.

## Incluye

- Base de conocimiento con 5 productos: cuenta, tarjeta, préstamo, plazo fijo y seguro.
- Preguntas frecuentes por producto.
- Instrucciones del agente listas para copiar.
- 6 preguntas de prueba.
- Chat simulado que responde con citas de fuente.
- Rutas recomendadas dentro de la app para cada producto.
- Guías visuales de 3 pasos para cuenta, tarjeta, préstamo, plazo fijo y seguro.

## Deploy

El workflow `Deploy GitHub Pages` publica el sitio desde la rama `main`.
